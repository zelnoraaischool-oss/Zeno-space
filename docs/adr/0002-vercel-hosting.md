# ADR 0002：配信先を Vercel にする（要件 17.2 からの変更）

- 状態：採用（発注者の指示による）。公開前に再判断する

## 背景

要件定義書 17.2 は、アプリ本体を Cloudflare Workers の静的アセット配信から出し、Vercel は使わないとしている。理由は「Vercel の無料 Hobby プランは非商用の個人利用に限られ、商品やサービスの宣伝も商用利用に当たる」ため。
一方で、発注者から「Vercel 接続前まで仕上げる」指示があった。

## 決定

- `vercel.json`（SPA 配信・キャッシュ・セキュリティヘッダー）と `middleware.ts`（クローラー向け OGP）を用意する。
- 成果物は静的ファイル（`dist/`）に保ち、Cloudflare への載せ替えもできるようにする。OGP の差し込みは Vercel Middleware と同じ処理を Worker でも書ける形にしておく。
- 固定費0円の前提（1.5）と Hobby の利用条件が衝突するため、公開前に次のどちらかを選ぶ。
  1. Vercel Pro に切り替える（月額の固定費が発生する）
  2. 要件どおり Cloudflare Workers から配信する

## 影響

- クローズドβ（招待制）までは Vercel で検証できる。一般公開（G3）の前に判断が必要。
